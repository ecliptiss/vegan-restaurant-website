# Vegan Restaurant Website

This website was originally made for a TSA Website Design challenge.

Our team of 4 were tasked with creating a vegan-style restaurant. My teammate and I focused on the website development of "Green Haven," our fictional restaurant serving vegan food from various cuisines across the globe.
In particular, the website has 4 main pages: "Home", "About Us", "Menu and Order", and "Explore" pages.

## Features:
- Adaptive layout for mobile screens
- Interactive menu with descriptions, add-to-cart, filters for different origins, and total/tax calculations
- Extensive use of Flexbox for clean organization of display elements
- Clickable SVG map to display information of various global cuisines
